# ADR-0019 — The movement method: intention → trajectory → material → vetos

Date: 2026-08-27. Status: accepted. Source: the implementation note delivered
with the chapter-7 entry-2 brief v2 (`briefs/note-implementation-mouvement.md`,
absorbed here).

## Context

After the rehearsal the diagnosis was acted: the stack produced conformity
without intention, a patchwork with no global consistency, every chapter
written the same way. The served context described facts, forms and
prohibitions, never what the entry must DO. Draw 6 of chapter 7 opened on our
own opening instruction, copied at 0.94 similarity.

## Decision

- The writing prompt stops describing boxes to traverse. It declares a
  MOVEMENT to accomplish (one sentence, first line), prose DIRECTIVES
  (trajectory), an available MATERIAL (replacing station instructions), and
  what the text does not do (vetos), in that strict order. The instruction
  must read as an instruction, not as prose that can be recited.
- Each entry of the spec gains `mouvement`, `trajectoire`, `matiere`,
  `forme` (accumulation required / allowed / absent; verdict present /
  absent). Stations and objects become available material, not steps.
- The drift changes mechanism: a full written passage (2–3 sentences) is
  inserted at a declared segment frontier, validated in both directions at
  import (pivot left open, no departure word, its suspension the only one in
  the entry). The short-approach bank remains for non-migrated chapters.
- The movement column (`mouvements-chapitres.md`) is DEEP; only the current
  chapter's line reaches the brief, extracted at build time; the entry guard
  (meta-terms, machinery, deep markers) runs on the assembled prompt.
- The grid gets one MANUAL line, first: "Is the declared movement
  accomplished?" That line is the judge; the automatic grid is a veto.

## Consequences

- Measured against the reference draw: prompt copy 0.94 → 0, opening entry
  90 words → 19, mass in target for the first time (557 on 450–600).
- The verification the note prescribed became the prompt snapshot suite:
  the served prompt of entry 2 is frozen, intention first.
- Generalising to the other chapters is author work: about thirty movements
  to write, one per entry, never generated.
