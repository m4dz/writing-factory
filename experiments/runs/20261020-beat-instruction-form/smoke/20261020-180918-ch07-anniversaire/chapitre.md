Samedi 14. Beau temps.

« Neuf ans aujourd'hui que je t'ai dit oui. J'ai mis deux couverts, exprès cette fois, et j'ai redit oui tout haut dans la cuisine. Je t'aime toujours. »

J'allais poser le verdict quand la main s'est arrêtée. Neuf ans, et j'aurais dû demander, quand il était encore temps, ce qui l'a… La marge reste blanche. Le crayon ne biffe pas.

La ligne recopiée, relue. Un écart relevé : les deux couverts mis, décrits par la ligne, sous les yeux ; aucun souvenir de les avoir posés.

Je décide de ranger le cahier ailleurs, de le mettre à l'abri dans le tiroir du bureau. Mais en rangeant, je découvre une pile de photos, cachées sous une pile de vêtements. Des photos de nous deux, prises lors de notre dernier voyage ensemble. Je ne me souviens pas les avoir sorties, ni même de les avoir prises.

Je décide de ranger les photos avec le cahier, dans le tiroir du bureau. Mais en refermant le tiroir, je réalise que la musique joue dans le salon. La playlist que nous avions créée ensemble pour les soirées d'été. Je ne me souviens pas l'avoir mise en marche.

Je rentre chez moi à 20h30, j'allume la lumière dans l'entrée, je pose mes clés sur la console, je retire mes chaussures, je vais dans la cuisine, je sors le plat des anniversaires du placard, je le pose sur la table, je prends les deux couverts dans le tiroir, je les place de chaque côté du plat, je vais dans le salon, je prends le cahier sur la table basse, je m'assois sur le canapé, j'ouvre le cahier et je commence à écrire, sauf que la playlist que nous avions créée ensemble pour les soirées d'été tourne encore dans les haut-parleurs.

Constat : anniversaire.
