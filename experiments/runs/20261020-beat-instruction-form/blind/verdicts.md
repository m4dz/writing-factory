# Verdicts — lecture à l'aveugle

Une ligne par entrée : le mouvement déclaré est-il accompli ? (oui / non / partiel), puis une note libre (le ton en particulier).

- E01 : partiel ; le mouvement est bon, un échec sur un personnage inventé (une fille) à la fin
- E02 : oui ; mouvement OK, un des meilleurs ton obtenus
- E03 : oui ; mouvement OK, le doute tient, un manque de densité
- E04 : oui ; mouvement OK, doute OK, légère répétition, manque de densité, ton plutôt bon
- E05 : partiel ; on tient quelque chose sur le doute, qui m'aboutit pas, mais l'ensemble se tient
- E06 : partiel ; excellent progression, densité correcte, mais une tentative de résolution du doute
