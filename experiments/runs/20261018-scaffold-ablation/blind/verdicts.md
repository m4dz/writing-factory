# Verdicts — lecture à l'aveugle

Une ligne par entrée : le mouvement déclaré est-il accompli ? (oui / non / partiel), puis une note libre.

- E01 : oui ; aucun détail, aucune tension, froide énumération
- E02 : non ; échec de construction, suivi d'une accumulation qui n'a pas de sens
- E03 : oui ; un des meilleurs tirages, un peu trop d'automatismes encore, mais la construction est claire et la progression de la tension évidente
- E04 : non ; on a de la densité, mais le ton sonne creux, et l'ensemble est un contre-sens de ce qu'on cherche à obtenir : le personnage ne tient pas son rôle
- E05 : non ; incohérent
- E06 : non ; le texte invente des narratifs, contre-sens à l'histoire
- E07 : non ; l'ensemble manque de cohérence, mais une phrase sort du lot `Je me suis assise dans le salon et j'ai repris le relevé de hier soir...` qui a un ton correct
- E08 : partiel ; le mouvement semble bon, mais le texte dérive sur des externalités qui ne peuvent avoir lieu
- E09 : partiel ; le texte invente des éléments impossibles (e.g. `Huit couverts ce soir.`)
- E10 : non ; les éléments essentiels sont manquants, le reste est inventé, pas de densité
- E11 : partiel ; il manque la tension principale des éléments d'anniversaire découvers, mais le ton va dans la bonne direction, malgré un manque de densité
- E12 : partiel ; le mouvement n'est pas centré sur les bons éléments, mais le ton va dans la bonne direction
- E13 : non ; échec sur la cohérence et la densité
- E14 : non ; incohérences et inventions
- E15 : non ; pas de mouvement, pas de profondeur
